# Танки (8-бит)

Многоязычная консольная игра «Танки» в ретро-стиле.  
Управляйте танком, уничтожайте врагов, собирайте бонусы и устанавливайте рекорды в классическом 8-битном стиле.

## Особенности
- Управление танком с помощью клавиш `WASD` или стрелок.
- Стрельба по врагам клавишей `Space` или `Enter`.
- 5 уровней сложности (враги появляются быстрее и точнее стреляют).
- Система здоровья (3 жизни) и бонусы: здоровье, ускорение, щит.
- Сохранение рекорда в локальный файл (best score).
- Цветной вывод в терминале (зелёный — игрок, красный — враги, жёлтый — бонусы).
- Анимация взрывов и движение с «пиксельной» плавностью.
- Перезапуск игры после поражения (клавиша `R`).

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости.

### Запуск на разных языках

1. **Python**  
   Установка: `pip install colorama`  
   Запуск: `python tanks.py`

2. **JavaScript (Node.js)**  
   Установка: `npm install chalk`  
   Запуск: `node tanks.js`

3. **Go**  
   Запуск: `go run tanks.go`

4. **Rust**  
   Сборка: `cargo build --release`  
   Запуск: `cargo run --release`

5. **Java**  
   Сборка: `javac Tanks.java`  
   Запуск: `java Tanks`

6. **C# (.NET Core)**  
   Запуск: `dotnet run`

7. **C++ (Linux)**  
   Сборка: `g++ -std=c++11 -o tanks tanks.cpp`  
   Запуск: `./tanks`

8. **Kotlin (JVM)**  
   Сборка: `kotlinc Tanks.kt -include-runtime -d tanks.jar`  
   Запуск: `java -jar tanks.jar`

## Управление
- `W` / `↑` – движение вверх
- `A` / `←` – движение влево
- `S` / `↓` – движение вниз
- `D` / `→` – движение вправо
- `Space` / `Enter` – стрельба
- `R` – перезапуск после окончания игры
- `Q` – выход
